# PashAstro_v2 — Астрофото трекер

## Структура проекта

| Файл | Назначение |
|------|-----------|
| `index.html` | Единственный файл приложения (SPA). Вся HTML-разметка, CSS-стили и JS-логика в одном файле. |
| `index.html.bak` | Резервная копия предыдущей версии (без раздела заметок, без редактирования сессий). |

## Используемые библиотеки

- **Tailwind CSS** (CDN) — утилитарный CSS-фреймворк для стилизации.
- Больше никаких внешних библиотек. Весь JS — нативный (vanilla).

## Архитектура

### Секции (табы)
5 навигационных вкладок в нижней панели:

1. **Главная (home)** — дашборд: общее накопленное время, количество сессий, статистика по типам объектов, пончик-диаграмма распределения экспозиции, топ-5 объектов по накоплению.
2. **Объекты (objects)** — каталог астрономических объектов. Поиск, фильтрация по типу (Галактика, Туманность, Скопление, Другое). CRUD через диалог.
3. **Сессии (sessions)** — журнал сессий съёмок, сгруппированный по годам. Детали сессии (локация, Bortle, сетап, камера, фильтр, кадры Light/Dark/Bias/Flat).
4. **Погода (weather)** — астропрогноз. Вердикт (Отлично/Удовлетворительно/Не подходит), облачность, ветер, точка росы, фаза Луны. Часовой прогноз.
5. **Заметки (notes)** — личные записи с заголовком и текстом.

### Хранение данных
- `localStorage` с ключом `ASTROLOG_V2_DATA`
- Схема: `{ version: 2, objects: [], sessions: [], notes: [] }`
- Отдельно хранятся `objects`, `sessions`, `notes` и `settings`
- Фотографии **не** хранятся в localStorage: файлы загружаются на imgbb.com, а в объекте лежит только массив ссылок `images[]` (id, url, displayUrl, thumbUrl, размер, дата). Обложка — поле `object.cover` = id выбранного фото.

### Фотографии объектов (ImgBB)
- API-ключ ImgBB и качество загрузки хранятся в `settings` (`imgbbKey`, `imageQuality`) и задаются в диалоге «Настройки профиля» → блок «Фотографии (ImgBB)».
- Пресеты качества: `original` (без сжатия, лимит ImgBB 32 МБ), `high` (2560 px, JPEG 90%), `medium` (1920 px, JPEG 85%), `low` (1280 px, JPEG 80%).
- Перед отправкой изображение сжимается через `canvas` (`compressImageForUpload`); GIF/SVG и мелкие файлы не пережимаются. PNG с прозрачностью получает чёрную подложку.
- Загрузка через `XMLHttpRequest` (`uploadToImgbb`) с реальным прогрессом в процентах; поддерживается множественный выбор файлов.
- Ограничения: лимит ImgBB — 32 МБ на файл. Ключ API виден в исходном коде страницы (только для личного использования).
- Удаление фото убирает только запись из приложения; сам файл остаётся на imgbb.com.

### Ключевые функции JS (фотографии)
- `objectCoverUrl(o)` — URL миниатюры обложки объекта
- `objectAvatarHtml(o)` — аватар объекта: фото-обложка или бейдж каталога
- `renderObjectGallery(o)` — сетка фотографий в карточке объекта
- `openImageViewer(o, imageId)` / `renderImageViewer()` — полноэкранный просмотр с навигацией
- `uploadObjectImages(o, files, statusEl, uploadBtn)` — пакетная загрузка
- `uploadToImgbb(file, onProgress)` / `compressImageForUpload(file)` — сжатие и отправка
- `removeObjectImage(o, imageId)` — удаление записи о фото

### Ключевые функции JS
- `renderApp()` — главная функция рендеринга, вызывает все остальные `render*`
- `updateDashboard()` — обновление дашборда
- `render()` — рендер списка объектов с учётом фильтра и поиска
- `renderSessions()` — рендер сессий, сгруппированных по годам
- `renderTopObjects()` — рендер топа объектов на главной
- `renderWeather()` — рендер погодного прогноза
- `renderNotes()` — рендер заметок
- `openDetails(object)` — открытие карточки объекта с историей сессий
- `openObjectForm()` / `openSession()` / `openNoteForm()` — открытие диалогов создания/редактирования
- Астрономические расчёты: `sunEquatorial()`, `sunAltitudeAt()`, `findSunCrossings()`, `gmst()`

### Демо-данные
